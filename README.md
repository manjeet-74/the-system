# THE SYSTEM

A **Solo-Leveling-inspired productivity RPG**. Clear daily quests, build streaks, defeat bosses,
raid with friends and rank up from **E → S** — a gamified layer over real-world goals.

100% free to run: Supabase free tier + Vercel hobby + Google Gemini free tier. No paid services.

## Features

**Core loop**
- **Daily quests** — 5 defaults plus your own, optionally recurring. Verify by checkbox, **GitHub commits**, or the **AI Judge** (Gemini grades your work against a rubric).
- **Stats, levels & ranks** — STR / INT / VIT / SENSE / AGI feed a level and a rank from E to S, with a live HUD.
- **Streaks** — server-enforced; missing a day applies stat decay and a Redemption Trial. Streaks multiply XP (up to **2×** at 30 days).
- **The Forge** — streak milestones (3/5/7/14/30) unlock bonus challenges.
- **Boss fights** — a weekly and a monthly boss for everyone, auto-created and auto-expired.
- **Analytics** — completion heatmap, stat growth, per-stat completion.

**Progression & identity**
- **Rank-Up Cinematic** — a full-screen "THE SYSTEM RECOGNIZES YOUR GROWTH" moment with particles and a synthesized sound sting.
- **Daily System Message** — one line a day from THE SYSTEM, generated by Gemini and cached.
- **Achievements & titles** — 15 milestones that pay coins and unlock equippable titles.
- **Shadow Exchange (store)** — spend earned coins on HUD themes, titles and portrait frames. Cosmetic only.
- **Profile** — edit name/class, lifetime stats, and a **procedural hunter portrait** (unique per player, changes with class and rank, downloadable as PNG).

**Social**
- **Rankings** — weekly XP / level / streak boards, global (opt-in) and guild-only.
- **Guilds** — up to 20 hunters with a shared weekly XP goal and invite links.
- **Co-op raids** — invite a friend to clear a boss together for bonus XP and coins.

**Platform**
- **Installable PWA** with offline shell and **web-push** reminders (works on Android, desktop, and iOS once added to the Home Screen).
- Optional email reminders (Resend).
- Native iOS/Android wrapper via Capacitor — see [DEPLOYMENT.md](./DEPLOYMENT.md#native-app-optional).

## Security model

The browser is untrusted. Everything that grants XP, coins, titles or rewards is decided in the
database by `SECURITY DEFINER` functions; clients only *ask*.

- Row-Level Security on every table; clients cannot write stats, wallet, achievements or purchases.
- Profile writes are column-restricted; cosmetics change only through ownership-checked RPCs.
- Coins are paid once per quest, so complete → undo → redo cannot farm them.
- AI grading is owner-only, single-use per submission (no re-rolling), rate-limited, and the submission text is treated as untrusted.
- Scheduled jobs require a shared `CRON_SECRET` (the public anon key cannot trigger them).
- The leaderboard is opt-in and never exposes email addresses.

## Run it

**Hosting your own copy?** Follow **[DEPLOYMENT.md](./DEPLOYMENT.md)** — Supabase, secrets, migrations,
functions, schedules and Vercel, step by step.

Local development:

```bash
npm install
cp .env.example .env        # fill in the VITE_* values from your Supabase project
npm run dev                 # http://localhost:5173
npm run build               # type-checks and builds
```
